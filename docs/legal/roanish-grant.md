# The upstream grant — verbatim record

This project forks [Roanish/i76](https://github.com/Roanish/i76), which
publishes **no `LICENSE` file**. The basis on which this fork is redistributable
is the explicit public permission recorded below.

It is transcribed here verbatim, in the repository, on purpose: a GitHub issue
can be edited, deleted, or lost with the account. The evidence for our right to
this code should not depend on a third party's hosting.

**Status: settled, not pending.** The maintainer was asked directly — twice, see
below — to apply a formal licence, and declined while reaffirming permission.
This informal grant is therefore the permanent basis, by the author's choice.
Nothing in this repository should suggest a licence is still being chased.

## What we read this as saying

Recorded as our interpretation, not as legal advice, so a future reader can see
the reasoning and disagree with it if warranted.

1. **The grant is broad and unconditional in its operative clause** — "feel free
   to use any parts of it you wish". It is not limited to particular files,
   does not exclude modification, and does not restrict the medium.

2. **"I am not trying to build a commercial product" is the author's reason for
   not licensing, not a restriction placed on us.** It explains their own
   motive. It is deliberately quoted in full above rather than paraphrased so
   nobody has to take our word for that reading.

3. **The one thing actually asked of us is attribution** — "in the spirit of the
   community, a shout out is appreciated if you do". Phrased as a courtesy
   rather than a condition, which makes honouring it a matter of decency rather
   than compliance. We honour it in `README.md` (Credit), in `THIRD-PARTY.md`,
   and in `LICENSE` itself. **Do not remove those.**

4. **The author confirmed the upstream code is clean** — "contains 0 (none) of
   the original game code or assets" — which is consistent with this project's
   own BYO-assets posture.

5. **They asked to be kept informed** — "Report back so i can follow your
   progress." That is a request worth actually honouring, not just recording.

## Consequences for our own licensing

Our own work is **MIT** (`LICENSE`). We can license our own contributions
however we choose; the forked portions rest on the grant above. We do **not**
relicense Roanish's code on their behalf, and `LICENSE` says so explicitly.

Because the grant is informal and permissive in spirit, applying stronger
copyleft than the author chose would not be honouring it — this is part of why
GPL-3 was considered and rejected on 2026-08-06 in favour of MIT. See
`THIRD-PARTY.md`.
